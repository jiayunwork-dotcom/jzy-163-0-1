一个朋友业余做音箱，最近想给一只 6.5 寸中低音单元配箱，问我能不能帮他做个网页工具：填入单元的 Thiele–Small 参数，调箱体容积和倒相管，立刻看到频响和阻抗曲线怎么变，还能把几套方案叠在一起比。他以前用的桌面软件停更了，新系统上装不上。

后端算两件事。第一件是低频小信号响应。输入单元参数 Fs、Qes、Qms（Qts 由二者导出并回显）、Vas、Re、Sd，以及箱体类型：闭箱给净容积 Vb 和箱体损耗 Ql；倒相箱另给倒相管截面积、长度和端部修正系数，由 Helmholtz 关系算出调谐频率 Fb。服务在对数频率网格上返回归一化声压级频响（1 W/1 m 灵敏度由单元参数导出，公式写进说明）、电阻抗的幅值和相位、-3 dB 截止频率 f3，闭箱另给 Qtc 和系统谐振频率 Fc。倒相箱阻抗在 Fb 两侧各有一个峰、Fb 附近是谷，闭箱只有一个峰。第二件是反向设计：闭箱按目标 Qtc 反求 Vb；倒相箱给定 Vb 和目标 Fb，在指定管径下反求管长，管长为负或超出箱体内部尺寸时如实报告无法实现。

后端测试要验证：闭箱 Qtc=Qts·√(1+Vas/Vb)、Fc=Fs·√(1+Vas/Vb)，Vb 减半时 Qtc 和 f3 升高；只把 Qts 加倍，Qtc 加倍；倒相管加长 Fb 下降，且与 Helmholtz 公式一致；倒相箱阻抗两峰的频率夹住 Fb；远低于谐振的频段，闭箱频响按每倍频程 12 dB 下降、倒相箱按 24 dB 下降（用渐近斜率判断）；反向设计的结果代回正向计算，Qtc 或 Fb 与目标一致；Vb 很大时闭箱结果趋于无限障板。Fs、Vas、Re、Sd、Vb 非正，Qes 或 Qms 非正，管截面积非正，频率上下限颠倒或点数超过 5000，都返回字段级错误。

页面这样组织：左侧是单元库和方案列表，单元参数与方案（箱体设置）都保存在后端，重启不丢；中间上下两张图，上面频响、下面阻抗，横轴对数；拖动 Vb、管长、管径等滑块，曲线按后端返回刷新，请求要做防抖，旧请求的结果不能覆盖新请求；可以勾选多个方案叠加对比，并在图上标出各自的 f3 和 Fb。曲线数据全部来自后端，前端不自己计算。

后端 Python 3.12 + FastAPI，单元和方案存 SQLite，数据库文件挂卷；拆出参数校验、闭箱模型、倒相模型、反向设计、单元与方案存储、路由等模块。网页部分基于 Vue 3，语言同样是 TypeScript，打包工具 Vite；拆出单元库、方案列表、曲线图、参数面板、请求层。pytest 覆盖后端行为，参数表单的校验逻辑也要有 Vitest 单测。部署上是两个容器：API 容器以 python:3.12-slim 为底；静态页面由 nginx:1.27-alpine 容器伺服，同时把 /api 请求转发到 API 容器，二者写在同一份 compose 文件里。
